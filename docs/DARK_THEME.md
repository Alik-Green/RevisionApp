# Dark theme

The Playful light palette is intentionally unchanged. The redesigned dark palette
uses a near-black evergreen canvas and four raised neutral surfaces, with accents
assigned by role instead of mixing unrelated hues:

| Role | Accent | Use |
| --- | --- | --- |
| Primary / positive | Leaf lime `#C4F27A` | Main actions, correct answers, current path nodes |
| Secondary | Aqua `#5AD9C4` | Secondary actions and active-course details |
| Tertiary / information | Sky `#85B7FF` | Supporting progress and information |
| Partial / reward | Amber `#F5C75E` | Partial-credit feedback and reward emphasis |
| Error | Coral `#FF917C` | Incorrect answers and error feedback |

Text uses soft white and muted sage; neutral surface steps separate the canvas,
cards, and raised panels. Course paths and dark-mode subject markers draw only
from the same five accents. The bright path-node glyphs use deep evergreen ink for
contrast.

Card and control radii are normalized in dark mode to a compact 6/10/12/16/20 dp
scale; thin progress indicators keep their pill ends. Existing light-mode corner
radii are preserved by the adaptive shape helper. The palette and component
treatments borrow broad lessons—clear feedback, focused
content, and visible progress—from Duolingo, Chess.com, Reddit, and Spotify; no
brand artwork or product assets are copied.
